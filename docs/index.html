遠端畫面

SmartRemote · 看畫面 / 遙控電腦

在電腦上開啟 SmartRemote，右鍵系統匣圖示就能看到房間碼與密碼；設定檔 control 開了才能遙控。畫面由兩台裝置直接連線傳送，不經過伺服器。網址後面加上「#房間碼/密碼」並加入書籤，下次打開就會自動連線。

鍵盤

輸入文字 (直接打到電腦上目前的輸入位置)

修飾鍵 (先點，再點下面的按鍵 = 組合鍵)

按鍵

常用組合

剪貼簿

電腦上最近複製的文字

放到電腦的剪貼簿 (之後在電腦上按 Ctrl+V 貼上)

用電腦 (滑鼠鍵盤) 遙控時，在畫面上按 Ctrl+V 會先把這台的剪貼簿傳過去再貼上；電腦上複製的文字也會自動放進這台的剪貼簿 (瀏覽器允許的話)。

電腦的檔案

    點資料夾打開，點檔案下載到這台裝置。上傳的檔案放在目前的資料夾，同名不會覆蓋。也可以直接把檔案拖到畫面上 (放到「下載」資料夾)。

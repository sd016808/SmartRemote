# SmartRemote

用手機或別台電腦的瀏覽器，**看**這台 Windows 電腦的畫面，並可以選擇**遙控**它（滑鼠、鍵盤、剪貼簿、傳檔案）。

- 畫面是兩台裝置**直接連線**，不經過伺服器，也不用設定路由器、不用開 port。
- 連線碼只透過 ntfy.sh 交換，內容用房間碼與密碼加密，ntfy 看不到內容。
- 程式是系統匣小程式，右下角圖示右鍵就能看房間碼與密碼、複製觀看網址。

## 使用方式

1. 執行 `SmartRemote.exe`，右下角系統匣會出現盾牌圖示。
2. 右鍵圖示 → **複製觀看網址**（網址後面已經帶有房間碼與密碼）。
3. 手機或別台電腦用瀏覽器開這個網址（可以加入書籤，下次一開就連線）。觀看頁：<https://sd016808.github.io/SmartRemote/>
4. 畫面出來後，要遙控可以按上面的「遙控」按鈕（需要設定檔 `control` 開啟）。

### 觀看頁操作

- 畫質三段都是每秒 60 張，只差解析度與流量：**省流量**（寬 1280，約 2.5 Mbps）、**標準**（寬 1920，約 6 Mbps）、**清晰**（原始解析度，最高 20 Mbps）。網路慢就選省流量。
- 電腦端（滑鼠鍵盤）：直接在畫面上點、打字。
- 手機：點一下 = 左鍵、兩指點 = 右鍵、長按後拖曳 = 拖曳、兩指上下滑 = 捲動。「鍵盤」可以打中文、按 Esc / F1~F12 / 組合鍵。
- 遙控中 **Ctrl + Alt + Shift** 一起按 = 結束遙控（滑鼠被畫面拉住時的保險）。
- 「剪貼簿」兩邊互傳文字；「檔案」瀏覽電腦的資料夾，可以下載到手機、從手機上傳（同名不覆蓋）。
- Ctrl+Alt+Del、鎖定畫面、UAC 確認視窗是 Windows 的安全畫面，遠端看不到也不能操作。

## 設定檔 settings.json

第一次執行會在 exe 旁邊建立 `settings.json`（用右鍵圖示 →「開啟設定檔」）：

```jsonc
{
  // 房間碼 / 密碼：不填 = 每次啟動隨機產生；填了就固定 (房間碼：英文字母或數字，至少 4 個字；密碼：至少 8 個字，可用英文、數字與符號，不能有空白和 /)
  "room": "",
  "password": "",
  // false = 只能看；true = 可以遙控這台電腦 (知道房間碼和密碼的人就能操作，密碼請設長一點)
  "control": false
}
```

改完設定要重開程式。房間碼和密碼填固定的話，書籤存一次就好。

## 安全

- 拿到房間碼和密碼的人能看你的畫面；`control` 開啟時還能**操作你的電腦**。密碼請設長一點，外洩了就改掉再重開。
- 右鍵圖示 →「中斷所有連線並暫停接受」：立刻中斷所有連線並暫停接受新的連線，再點一次恢復。
- 右鍵圖示 →「允許遙控」可以在程式執行中開關遙控；關閉後已連線的人也只能看。
- 觀看端如果就開在這台電腦上，會自動改成只能看（遙控自己的畫面會讓滑鼠被拉住）。
- 每次連線的時間、來源位址、裝置、有沒有遙控、傳了哪些檔案，都記錄在 `logs/remote_connections.log`（右鍵圖示 →「開啟連線紀錄」），不會自動刪除。

## 限制

- 雙方網路都不允許直連時連不上（沒有 TURN 中繼伺服器）。觀看頁會顯示「連不上」，換個網路再試。
- 安全桌面（UAC、鎖定畫面、登入畫面）看不到也不能操作。
- 沒有接螢幕的電腦沒有畫面可以傳；需要 HDMI 假負載或虛擬顯示器。
- 需要 Windows 10 以上。

## 從原始碼建置

需要 .NET 8 SDK。

```powershell
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained true -o publish
```

開發時可以設環境變數 `SMARTREMOTE_DRYRUN=1`：遙控的滑鼠、鍵盤、剪貼簿只寫日誌，不真的動作（測試用）。

## 協定

觀看頁與程式之間的協定（連線碼交換用 ntfy 的主題與 AES-GCM 加密、畫面與遙控走 WebRTC DataChannel）寫在 `Core/RemoteView.cs`、`Core/RemoteSession.cs`，觀看頁在 `docs/index.html`。改協定時兩邊要一起改。
